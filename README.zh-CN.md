# 论文阅读 Skill

[English](README.md) | [简体中文](README.zh-CN.md)

这是一个帮助你读懂单篇学术论文的 Skill。默认情况下，它会依次提供快速了解、标准解读和顺序伴读。你可以提供论文 PDF、链接、DOI、arXiv 编号、标题或粘贴的正文。

## 功能

- 默认流程：先用一句话概括论文并判断所属领域，再做标准解读，最后按原文顺序伴读
- 深入梳理论文的任务输入与输出、数据集来源与划分、基线方法、消融实验和评价指标
- 顺序伴读：逐段精炼翻译；在正文首次提到公式、图或表时，紧接着按原文顺序解释
- 完成整篇顺序伴读后，提出三个可借鉴的想法或方法、三个可迁移的领域，以及三个面向 A 类会议的具体研究 idea
- 用清楚易懂的语言解释研究问题、方法、公式和证据
- 解读图表时说明实际检查了哪些内容
- 区分作者的主张、论文报告的证据和进一步分析
- 适用于实证、理论和系统类论文，不强行套用同一套实验模板

它不是论文搜索引擎，也不会自动推荐每日论文。长论文可能需要多轮完成伴读；每次暂停时会说明已经读到哪里，以及下次从哪里继续。你也可以明确要求更窄的范围，例如只做快速筛选。默认情况下，它不会做多篇论文综述或冗长的审计报告。

## 在 Codex 中安装

将此目录复制到个人 Codex skills 目录：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills/paper-reading"
cp SKILL.md "${CODEX_HOME:-$HOME/.codex}/skills/paper-reading/SKILL.md"
```

如果 Skill 没有立即显示，请重启或刷新 Codex。支持 `SKILL.md` 格式的兼容 Skill 安装器也可以安装它。

## 使用方法

提供一篇论文或它的标识信息，并说明你想了解什么。例如：

- “快速讲一下这篇论文，重点告诉我值不值得细读。”
- “一句话讲清这篇论文，并告诉我它属于什么领域。”
- “解释一下这篇论文。”（默认依次输出快速了解、标准解读和顺序伴读）
- “带我梳理一下方法，并解释关键公式。”
- “按顺序伴读 Figure 3 所在章节，读到图时解释它是否支持作者的主张。”
- “深入批判性地解读这篇论文。”
- “逐段精炼翻译这篇论文的 Introduction，保留段落顺序和引用。”
- “按文章顺序伴读：每段先精炼翻译，遇到公式、图或表就紧接着解释，再继续下一段。”
- “完整顺序伴读后，接着给出三个可借鉴的想法、三个迁移领域，以及三个面向 A 类会议的具体研究 idea。”
- “深入拆解实验：数据集从哪来、怎么划分、baseline 和 ablation 分别是什么、指标怎么解释？”
